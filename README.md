# s17 Labs / assets

Official brand asset library. Logos, icons, fonts, and guidelines — everything needed to keep s17 Labs consistent across projects.

---

## Structure

```
assets/
├── org-branding/       # Logos, icons, and social banners
├── brand-guidelines/   # Visual identity guidelines and previews
└── fonts/              # Brand typefaces
```

| Folder | Contents |
|---|---|
| `org-branding/` | Logo variants (dark, light, transparent), icon variants, Twitter/X banners |
| `brand-guidelines/` | Brand guidelines README, color and font preview images |
| `fonts/` | Aldrich.ttf and font licensing info |

## Quick Reference

### Colors
| Name | Hex | Usage |
|---|---|---|
| Primary bg | `#0e0e10` | Page and app backgrounds |
| Accent | `#ff4136` | Highlights, hover states, CTAs |
| Primary text | `#f1f1f1` | Body text on dark backgrounds |
| Secondary text | `#868686` | Subtitles, muted content |

### Typography
| Role | Font |
|---|---|
| Display / Headings | Aldrich |
| Body | Verdana |

## Guidelines

See [`brand-guidelines/`](./brand-guidelines/) for the full visual identity doc. Short version:

- Use the correct logo variant for the background (dark vs light)
- Don't recolor, stretch, or distort the logo
- Accent red (`#ff4136`) is for highlights only — not large fills
- Aldrich is for headings/display only, not body copy
- Always written as **s17 Labs** — never S17 Labs, s17labs, or S17labs
