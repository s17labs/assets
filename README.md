# s17 Labs / assets

Official brand asset library — logos, icons, fonts, and images. Just the
files; everything documented lives elsewhere (links below).

## Structure

```
assets/
├── org-branding/       # Logos, icons, and social banners
└── fonts/              # Brand typefaces
```

| Folder | Contents |
|---|---|
| [`org-branding/`](./org-branding/) | Logo variants (dark, light, transparent), icon variants, social banners |
| [`fonts/`](./fonts/) | Aldrich.ttf and font licensing info |

## Usage

Reference assets via raw GitHub URL:

```
https://raw.githubusercontent.com/s17labs/assets/main/org-branding/s17labs-logo-dark.png
```

## Guidelines

- Use the correct logo variant for the background (dark vs light)
- Don't recolor, stretch, or distort the logo
- Always written as **s17 Labs** — never S17 Labs, s17labs, or S17labs

## Brand docs (elsewhere)

- [Design system](https://s17labs.github.io/design/) — colors, typography,
  iconography, components, and usage rules (single source of truth)
- [s17labs.github.io](https://github.com/s17labs/s17labs.github.io) — homepage,
  tools, and full repo docs (`docs/README.md`)
