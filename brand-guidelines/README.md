# 📖 s17 Labs. | Brand Guidelines

Official visual and identity standards for **S17 Labs**. This guide serves as the single source of truth for our design language, ensuring consistency across all modern web projects.

---

## 🎨 Color Palette
Designed for high-legibility and a developer-centric, dark-mode-first experience.

| Element | Hex Code | Preview | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | `#0E0E10` | ⬛ | Primary background for all web surfaces. |
| **Accent** | `#FF4136` | 🟥 | Square icon, CTAs, and performance highlights. |
| **Primary Text** | `#F1F1F1` | ⬜ | Headlines and primary body content. |
| **Secondary Text**| `#868686` | 🔘 | Metadata, captions, and deactivated states. |

---

## 🔡 Typography
We use **Aldrich** for all branding. Its squared-off, technical proportions mirror the geometry of our systems.

- **Primary Font:** Aldrich
- **Headings:** Aldrich Regular (Sentence Case or All Caps)
- **Body:** Aldrich Regular
- **Code:** Aldrich Regular or *JetBrains Mono* (Fallback)

---

## 🖼️ Logo System
The logo is built on a modular "Red Square" concept.

### 1. The Main Mark (Horizontal)
The primary logo consists of the red square followed by `s17 Labs.` in the Aldrich typeface. This is used for GitHub Organization headers and navigation bars.

### 2. The Icon (Avatar)
The solid red square (`#FF4136`) acts as our profile picture.
- **GitHub/X Avatar:** The red square should be centered within a `#0E0E10` field to maintain proper padding.

### 3. Usage Rules
- **Clear Space:** Maintain a "half-square" distance of empty space around the logo.
- **Backgrounds:** Use the `#F1F1F1` text version on dark backgrounds and the `#0E0E10` text version on light backgrounds.
- **No Distortion:** Do not stretch, skew, or rotate the square or the typeface.
