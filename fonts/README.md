# fonts/

Brand typefaces used across s17 Labs projects.

| File | Font | Role | License |
|---|---|---|---|
| `Aldrich.ttf` | Aldrich | Display / Headings | Google Fonts (OFL) |
| — | Verdana | Body copy | System font — no file needed |

Aldrich is used for all headings and the wordmark. Do not use it for body copy.

---

## Load via Google Fonts

If you don't have the `.ttf` locally, use the Google Fonts CDN instead:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Aldrich&display=swap" rel="stylesheet">
```
